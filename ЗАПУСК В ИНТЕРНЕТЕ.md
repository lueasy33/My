# Как выложить сайт «Аладдин» в интернет

Итог: сайт открывается с любого телефона по защищённому адресу (замочек в браузере).
Сертификат HTTPS получается и продлевается сам. Время — около 30 минут, стоимость —
от ~300 ₽ в месяц за сервер.

---

## Шаг 1. Арендуйте сервер (VPS)

Подойдёт любой российский хостинг: Timeweb Cloud, Selectel, REG.RU, Beget.
Хватит самого простого тарифа:

- **1–2 ядра, 2 ГБ памяти, 30+ ГБ диска**
- система — **Ubuntu 24.04** (или 22.04)

После оплаты хостинг покажет **IP-адрес** сервера и **пароль root** (в панели или в письме).

Если будете загружать много видео прямо на сайт — берите диск 50–100 ГБ.
Либо выкладывайте видео на RuTube / YouTube и вставляйте ссылку: так даже быстрее для сотрудников.

## Шаг 2. Адрес сайта (можно пропустить)

**Без домена.** Ничего делать не нужно. Сайт получит бесплатный адрес вида
`https://85-192-10-20.sslip.io` (это ваш IP через дефисы). Для прогона этого достаточно.

**Со своим доменом.** Например, поддомен `learn.shop-aladdin.ru`. В настройках DNS домена
добавьте **A-запись**: имя `learn`, значение — IP сервера. Запись начинает работать
через 5–60 минут.

## Шаг 3. Установка — одна команда

Откройте на своём компьютере **PowerShell** (Windows) или **Терминал** (Mac) и подключитесь к серверу:

```bash
ssh root@IP-СЕРВЕРА
```

Компьютер спросит, доверять ли серверу: напишите `yes`. Затем введите пароль root —
символы при вводе не видны, это нормально.

На сервере выполните одну из команд.

**Если репозиторий на GitHub открытый:**

```bash
curl -fsSL https://raw.githubusercontent.com/lueasy33/My/main/install.sh | bash
```

**Если репозиторий закрытый:**

```bash
apt-get update && apt-get install -y git && git clone https://github.com/lueasy33/My.git /opt/aladdin && bash /opt/aladdin/install.sh
```

GitHub спросит:

- **Username** — `lueasy33`;
- **Password** — сюда вводится не пароль от GitHub, а токен. Как его получить:
  1. На github.com откройте Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. В Repository access выберите только репозиторий `My`.
  3. В Permissions → Contents поставьте `Read-only`.

Скрипт задаст три вопроса:

1. **Домен** — впишите свой или просто нажмите Enter, если домена нет.
2. **Телефон и имя администратора** — так вы будете входить на сайт.
3. **Пароль администратора** — от 8 символов, при вводе не показывается.

Через 3–5 минут скрипт напишет «Готово!» и адрес сайта. Откройте его. Если браузер
сначала покажет ошибку сертификата, подождите 1–2 минуты и обновите страницу:
сертификат выдаётся при первом обращении.

## Шаг 4. Подготовка к прогону

Войдите на сайт как администратор и пройдите по порядку:

1. **Управление → Филиалы** — добавьте филиалы.
2. **Управление → Сотрудники** — заведите сотрудников: имя, телефон, филиал, временный пароль.
3. **Управление → Контент** — создайте курс, внутри него уроки (текст, фото, видео, тест).
   Опубликуйте уроки и курс.
4. **Управление → Вкусы** — добавьте бренды и вкусы. Можно загрузить списком из CSV.
5. **Управление → Мастерская** — при желании свои достижения, статусы и аватарки.

Затем разошлите сотрудникам адрес сайта, их телефон для входа и временный пароль.
На телефоне сайт можно добавить на главный экран (Поделиться → «На экран Домой»),
и он будет открываться как приложение.

На что попросить обратить внимание во время прогона:

- понятно ли, куда нажимать и что делать дальше;
- что не грузится, падает или выглядит криво (лучше со скриншотом);
- хватает ли времени на уроки, понятны ли вопросы в тестах;
- интересно ли тренировать вкусы, не слишком ли легко или сложно.

## Обновление сайта

Когда на GitHub появилась новая версия, подключитесь к серверу и выполните:

```bash
bash /opt/aladdin/update.sh
```

Для закрытого репозитория GitHub снова спросит логин и токен.
Перед обновлением скрипт сам делает копию базы. Сотрудники, прогресс и загруженные
файлы сохраняются.

## Резервные копии

Сайт раз в сутки сам сохраняет копию базы в `/opt/aladdin/data/backups` и хранит 14 последних дней.
Раз в месяц полезно скачать папку `data` к себе — на случай, если с сервером что-то случится.
Команда выполняется на своём компьютере:

```bash
scp -r root@IP-СЕРВЕРА:/opt/aladdin/data ./aladdin-data-копия
```

## Если что-то пошло не так

Все команды выполняются на сервере, в папке `/opt/aladdin` (`cd /opt/aladdin`).

| Что видите | Что делать |
|---|---|
| Сайт не открывается со своим доменом | Проверьте, что A-запись указывает на IP сервера (обновляется до 1 часа) |
| Ошибка сертификата дольше 5 минут | `docker compose logs caddy --tail 50`. Если сертификат не выдаётся на адрес sslip.io, используйте свой домен: исправьте `DOMAIN` в файле `.env` (`nano .env`) и выполните `docker compose up -d` |
| Забыли пароль администратора | `docker compose exec app npm run admin -- +79001234567 "Имя" новый-пароль` |
| Нужно посмотреть ошибки | `docker compose logs app --tail 100` |
| Перезапустить | `docker compose restart` |

## Важно

- Демо-база с тестовыми сотрудниками и паролем `aladdin2026` на сервер не попадает.
  На сервере база создаётся пустой, с вашим администратором.
- Для работы с реальными сотрудниками нужны согласия на обработку персональных данных (152-ФЗ).
  Тематика табака (18+) — согласуйте формулировки с юристом.
