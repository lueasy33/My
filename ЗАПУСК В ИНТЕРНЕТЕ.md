# Как выложить сайт «Аладдин» в интернет

Итог: сайт открывается по адресу вроде `https://learn.shop-aladdin.ru` с любого телефона,
по защищённому соединению (замочек в браузере). Сертификат получается и продлевается сам.

Понадобится примерно 1 час и ~400–700 ₽ в месяц.

---

## Что купить

1. **Сервер (VPS)** у любого российского хостинга: Timeweb Cloud, Selectel, REG.RU, Beget.
   Достаточно самого простого тарифа: **1–2 ядра, 2 ГБ памяти, 30+ ГБ диска, Ubuntu 22.04 или 24.04**.
   Если будете загружать много видео прямо на сайт — берите диск побольше (50–100 ГБ)
   или выкладывайте видео на RuTube / YouTube по ссылке (так даже быстрее для сотрудников).
2. **Домен** — можно поддомен уже существующего сайта, например `learn.shop-aladdin.ru`.
   В настройках DNS домена добавьте **A-запись**: имя `learn`, значение — IP-адрес сервера.

## Установка (один раз)

Подключитесь к серверу по SSH (хостинг даёт команду и пароль в письме) и выполните по очереди:

```bash
curl -fsSL https://get.docker.com | sh
```

Скопируйте на сервер папку `aladdin` (без `node_modules`, `build` и `data`).
Проще всего — заархивировать и загрузить через панель хостинга, либо командой с вашего компьютера:

```bash
scp -r aladdin root@IP-СЕРВЕРА:/opt/
```

Затем на сервере:

```bash
cd /opt/aladdin
cp .env.example .env
nano .env
```

В `.env` впишите свой домен, телефон и пароль первого администратора (пароль — от 8 символов).
Сохраните: `Ctrl+O`, `Enter`, `Ctrl+X`.

```bash
docker compose up -d --build
```

Через 1–2 минуты сайт откроется по вашему адресу. Войдите телефоном и паролем из `.env`,
дальше всё делается в интерфейсе: филиалы → сотрудники → курсы и уроки.

## Обновление сайта

Загрузите новую версию папки поверх старой (папку `data` не трогайте) и выполните:

```bash
cd /opt/aladdin
docker compose up -d --build
```

Все данные — сотрудники, прогресс, загруженные файлы — лежат в папке `data` и при обновлении сохраняются.

## Резервные копии

Сайт сам раз в сутки сохраняет копию базы в `data/backups` (хранит 14 последних дней).
Раз в месяц полезно скачать папку `data` к себе — на случай, если с сервером что-то случится:

```bash
scp -r root@IP-СЕРВЕРА:/opt/aladdin/data ./aladdin-data-копия
```

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| Сайт не открывается | Проверьте, что A-запись домена указывает на IP сервера (обновляется до 1 часа) |
| «Неверный номер или пароль» у админа | `docker compose exec app npm run admin -- +79001234567 "Имя" новый-пароль` |
| Нужно посмотреть ошибки | `docker compose logs app --tail 100` |
| Перезапустить | `docker compose restart` |

## Важно перед запуском

- Не переносите на сервер демо-базу (`data/aladdin.db` с тестовыми сотрудниками и паролем `aladdin2026`).
  На сервере база создастся пустой, с вашим администратором.
- Для работы с реальными сотрудниками нужны согласия на обработку персональных данных (152-ФЗ)
  и политика конфиденциальности. Тематика (табак, 18+) — согласуйте формулировки с юристом.
