- **Правило COIL (решение Евгения, не менять):** урок +15, тест +10, без ошибок +15, курс +40, вход в день +5, серии 30/70/200, тренажёр +2 за верный ответ, +18 за первую тренировку дня, +10 за тренировку без ошибок, плюс COIL за достижения.
- **Правильные ответы теста** показываются только после сдачи (решение Евгения 19.11).

## Жёсткие правила (нарушать нельзя)

1. **Только ветка `deepseek`.** Перед началом: `git switch deepseek`. Коммитить только туда. Ветки `mvp-tests` и `main` не трогать. **Ничего не пушить** (`git push` запрещён).
2. **Перед каждым коммитом — `npm test`.** Коммит только если все тесты зелёные. Упал тест — чинить или откатить свою правку (`git checkout -- <файл>`), а не править тест под ошибку.
3. **Секреты и личные данные не открывать и никуда не отправлять** (серверы DeepSeek в Китае):
   - не открывать и не читать папку `data/` (база сотрудников, ключи сессий, загрузки), файлы `.env`, `*.db`, `data/session-secret`, `data/vapid.json`;
   - не вставлять в чат ФИО, телефоны, пароли, ключи;
   - демо-данные для тестов создаются сами во временной папке — их тоже не выводить в чат.
4. **Ничего не удалять** (файлы, папки, ветки) и **не сбрасывать базу** (`npm run seed`, `npm run reset`, `FORCE=1` — запрещено).
5. **Не запускать сервер на порту 8080** — он может быть занят. Тесты сами берут случайный порт.
6. **Править только файлы, названные в задаче.** Маленькими шагами: одна задача — один коммит.
7. **Не менять правила COIL, тексты уроков и решения Евгения.** Если задача требует решения человека — пропусти её и запиши вопрос в «Сделано» внизу.
8. **Застрял больше чем на 3 попытки** — остановись, запиши в «Сделано», что не получилось и почему, переходи к следующей задаче.
9. После каждой задачи допиши строку в раздел «Сделано DeepSeek» внизу этого файла и закоммить вместе с задачей.

Формат коммита: `Короткое описание по-русски` + пустая строка + что сделано + строка `Сделано DeepSeek, проверит Claude`.

## Задачи по порядку

### Задача 1. Бонус «тренировка без ошибок» недостижим для новичка

- **Что не так:** новичку тренировка дня даёт 4 новых вкуса (`NEW_PER_SESSION = 4` в `server/routes/flavors.js`). А бонус «без ошибок» (+10 COIL) требует минимум 5 ответов: строка `const perfect = total >= 5 && correct === total` в обработчике `POST /api/flavors/session/finish`. Получить его новичок не может.
- **Что сделать:** заменить `total >= 5` на `total >= NEW_PER_SESSION` (константа уже есть в этом же файле). Суммы бонусов не менять.
- **Файлы:** `server/routes/flavors.js`, `test/flavors.test.js`.
- **Тест:** в `test/flavors.test.js` добавить проверку: 4 верных ответа (через `POST /api/flavors/answer`) → `POST /api/flavors/session/finish` → `perfect === true`, начислено 18 + 10 COIL. И что 3 верных ответа → `perfect === false`. Посмотри, как устроены соседние тесты в этом файле, и сделай так же.
- **Готово, когда:** `npm test` весь зелёный, новых тестов +2.

### Задача 2. Несуществующий файл отдаётся как страница сайта (200 вместо 404)

- **Что не так:** запрос `/assets/net-takogo.png` возвращает код 200 и HTML главной страницы. Браузер считает, что картинка есть, и показывает пустоту; ошибки не видно.
- **Где:** `server/index.js`, `app.setNotFoundHandler(...)` (около строки 473). Сейчас всё, что не начинается с `/api`, получает `index.html`.
- **Что сделать:** если путь начинается с `/assets/` или `/uploads/`, или последний кусок пути имеет расширение файла (`.png .jpg .jpeg .webp .gif .svg .ico .js .css .map .json .txt .woff .woff2 .mp4 .pdf`), — отвечать `404` с текстом `Не найдено`. Остальные адреса (например `/ranking`, `/lesson/3`) — как раньше, `index.html` с кодом 200: это страницы приложения.
- **Файлы:** `server/index.js`, `test/static.test.js`.
- **Тест:** в `test/static.test.js`: `/assets/net-takogo.png` → 404; `/uploads/net.jpg` → 404; `/ranking` → 200 и HTML; `/lesson/1` → 200 и HTML.
- **Готово, когда:** `npm test` весь зелёный.

### Задача 3. Лимит неверных паролей по номеру телефона, независимо от адреса

- **Что не так:** в `server/index.js`, обработчик `POST /api/auth/login`, лимит считается по ключу «телефон + IP». Сменив адрес (мобильный интернет), можно подбирать пароль к одному номеру бесконечно.
- **Что сделать:** оставить существующий лимит как есть и **добавить второй счётчик только по номеру**: 10 неверных паролей к одному номеру за 15 минут (с любых адресов) → этот номер блокируется на 15 минут, ответ `429` с тем же текстом, что сейчас («Слишком много попыток. Повторите через N мин.»). Успешный вход сбрасывает оба счётчика. Хранить в памяти (`Map`), как сейчас.
- **Файлы:** `server/index.js`, `test/security.test.js`.
- **Тест:** подсказка — у сервера `trustProxy` включён, поэтому адрес можно подменять заголовком `X-Forwarded-For`. 10 неверных паролей к одному номеру с 10 разных `X-Forwarded-For` → 11-я попытка даже с верным паролем → 429. Посмотри, как устроен соседний тест про 5 попыток, и возьми тот же демо-номер оттуда (не выводи его в чат).
- **Готово, когда:** `npm test` весь зелёный.
