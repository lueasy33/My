- **Работает:** вход по телефону и паролю → урок → тест (3 попытки, пауза 10 мин, порог 70 %) → начисление COIL → рейтинг; тренажёр вкусов; магазин; админка.
- **Тесты:** `npm test` — 56 проверок, все зелёные (главный путь, безопасность, тренажёр, статика, защита базы).
- **Правило COIL (решение Евгения, не менять):** урок +15, тест +10, без ошибок +15, курс +40, вход в день +5, серии 30/70/200, тренажёр +2 за верный ответ, +18 за первую тренировку дня, +10 за тренировку без ошибок, плюс COIL за достижения.
- **Правильные ответы теста** показываются только после сдачи (решение Евгения 19.11).

## Жёсткие правила (нарушать нельзя)

1. **Только ветка `deepseek`.** Перед началом: `git switch deepseek`. Коммитить только туда. Ветки `mvp-tests` и `main` не трогать. **Ничего не пушить** (`git push` запрещён).
2. **Перед каждым коммитом — `npm test`.** Коммит только если все тесты зелёные. Упал тест — чинить или откатить свою правку (`git checkout -- <файл>`), а не править тест под ошибку.
3. **Секреты и личные данные не открывать и никуда не отправлять** (серверы DeepSeek в Китае):
   - не открывать и не читать папку `data/` (база сотрудников, ключи сессий, загрузки), файлы `.env`, `*.db`, `data/session-secret`, `data/vapid.json`;
   - не вставлять в чат ФИО, телефоны, пароли, ключи;
   - демо-данные для тестов создаются сами во временной папке — их тоже не выводить в чат.
4. **Ничего не удалять** (файлы, папки, ветки) и **не сбрасывать базу** (`npm run seed`, `npm run reset`, `FORCE=1` — запрещено).
5. **Не запускать сервер на порту 8080** — он может быть занят. Тесты сами берут случайный порт.
6. **Править только файлы, названные в задаче.** Маленькими шагами: одна задача — один коммит.
7. **Не менять правила COIL, тексты уроков и решения Евгения.** Если задача требует решения человека — пропусти её и запиши вопрос в «Сделано» внизу.
8. **Застрял больше чем на 3 попытки** — остановись, запиши в «Сделано», что не получилось и почему, переходи к следующей задаче.
9. После каждой задачи допиши строку в раздел «Сделано DeepSeek» внизу этого файла и закоммить вместе с задачей.

Формат коммита: `Короткое описание по-русски` + пустая строка + что сделано + строка `Сделано DeepSeek, проверит Claude`.
