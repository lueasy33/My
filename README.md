# Аладдин — платформа обучения сотрудников

Закрытый сайт для обучения продавцов сети «Аладдин»: курсы и уроки с тестами,
тренажёр вкусов в духе Duolingo, опыт (XP), уровни, валюта COIL, достижения,
магазин аватарок и статусов, рейтинг, 24 темы оформления, аналитика для администратора.

Регистрации нет: сотрудников заводит администратор, вход — по телефону и паролю.
Роли две: **сотрудник** и **администратор**.

## Запуск на своём компьютере

1. Установите [Node.js](https://nodejs.org) версии LTS (22.5 или новее).
2. Windows — дважды кликните `start.bat`. macOS / Linux — `./start.command`.
   Первый запуск ставит компоненты, собирает сайт и создаёт демо-базу (1–3 минуты).
3. Откройте http://localhost:8080

Демо-входы (пароль у всех `aladdin2026`): администратор `+7 910 123-45-67`,
сотрудник `+7 910 333-44-55`. Подробнее — в [ЧИТАЙ-МЕНЯ.txt](ЧИТАЙ-МЕНЯ.txt).

## Запуск в интернете

Docker + Caddy (HTTPS получается автоматически). Пошагово — в
[ЗАПУСК В ИНТЕРНЕТЕ.md](ЗАПУСК%20В%20ИНТЕРНЕТЕ.md). На сервере база создаётся пустой,
без демо-сотрудников; первый администратор берётся из файла `.env`.

## Для разработчика

- Сервер: Node.js + Fastify, база SQLite (встроенный `node:sqlite`), папка `server/`.
- Интерфейс: React + Vite, папка `src/`. Темы — переменные в `src/tokens.css`.
- `npm run dev` — сервер и интерфейс с автоперезагрузкой, `npm run build` — сборка,
  `npm run seed` — демо-база, `npm run admin -- +79001234567 "Имя" пароль` — создать администратора.
- Данные (`data/`: база, загрузки, резервные копии, ключ сессий) в репозиторий не попадают.
